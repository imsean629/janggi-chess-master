# 장기·체스 마스터 (웹 / 휴대폰 지원)

첫 화면에서 **장기** 또는 **체스**를 고르면 각각의 "마스터"가 열립니다. 내 진영을 고르고, **상대가 실제로 둔 수를 직접 입력**하면 내 차례에 **최선의 수 Top 3**를 판 위 화살표와 점수로 추천해 줍니다.
설치·빌드가 필요 없는 정적 웹앱이라 PC 브라우저와 휴대폰에서 똑같이 동작하고, 계산은 전부 기기 안에서 이뤄집니다.

## 사용법 (공통)

1. **설정**: 내 진영과 생각 시간(1·3·8·20초)을 고르고 `대국 시작`.
2. **내 차례**: 추천 수가 판 위에 화살표(1위 주황, 2·3위 파랑·보라)로 표시되고, 아래에 후보 목록·점수·예상 수순이 나옵니다. `추천대로 두기`를 누르거나 원하는 말을 직접 눌러 둡니다.
3. **상대 차례**: 실제 대국에서 상대가 둔 수를 그대로 입력합니다. **말을 누르고 → 도착 칸을 누르면** 끝이고, 입력하자마자 다음 추천을 계산합니다.
4. `무르기`(입력 실수 정정), `뒤집기`, 기보 보기, 설정(생각 시간·후보 수·상대 차례 예상 수 표시)을 대국 화면에서 쓸 수 있습니다.
5. 진행 중인 대국은 게임별로 자동 저장되어 다시 열면 `이어서 두기`로 복원됩니다. 첫 화면에도 진행 중인 대국이 표시됩니다.

### 장기
- 초/한 진영, 초·한 각각의 마·상 차림(안상·바깥상·마상마상·상마상마)을 고릅니다.
- `한수쉼`을 지원합니다. **빅장**은 무승부로 끝내지 않고 그대로 이어 가며, 상단에 `빅장` 표시만 나옵니다.
- 좌표는 `(열,행)`으로, 판 가장자리 숫자와 같습니다.

### 체스
- 백/흑을 고르고 **표준 배치** 또는 **FEN 입력**(체스 사이트의 "FEN 복사" 값을 붙여 넣기)으로 시작합니다.
- 캐슬링은 킹을 두 칸 옮기면 되고, 폰이 끝 줄에 닿으면 승격할 기물(퀸·룩·비숍·나이트)을 고르는 창이 뜹니다. 앙파상도 지원합니다.
- 체크메이트·스테일메이트·기물 부족은 대국 종료로 처리합니다. 3회 반복·50수 규칙은 "무승부 요청 가능"으로 알려 주고 대국은 계속됩니다(실제 규칙처럼 요청해야 무승부).
- 기보는 기물 그림 표기(♘f3)로 보여 주며, 메뉴에서 **현재 국면 FEN**과 **기보(PGN)** 를 복사할 수 있습니다.

## 다른 사람에게 주기 (HTML 파일 하나)

프로젝트 루트의 **`장기체스마스터.html`** 파일 하나만 주면 됩니다. 스타일·엔진·아이콘이 모두 들어 있어서, 받은 사람은 더블클릭만 하면 인터넷 없이 장기·체스를 모두 쓸 수 있습니다.
`web/` 폴더의 원본을 고친 뒤에는 아래 명령으로 다시 만드세요.

```bash
node tools/build-single.mjs
```

한 파일 버전은 첫 화면/장기/체스를 주소의 `#janggi`, `#chess`로 전환하며, 저장된 대국은 폴더 버전과 같은 방식(브라우저 저장소)으로 이어집니다. 홈 화면 설치(PWA) 기능은 폴더 버전을 HTTPS로 올렸을 때만 동작합니다.

## 실행 방법

### PC에서
프로젝트 루트에서 아래를 실행한 뒤 브라우저에서 `http://localhost:8000` 을 엽니다. (`web/index.html`을 직접 열어도 되지만, 그 경우 오프라인 설치 기능은 동작하지 않습니다.)

```bash
python -m http.server 8000 --directory web
```

### 같은 Wi-Fi의 휴대폰에서

```bash
python -m http.server 8000 --directory web --bind 0.0.0.0
```

PC의 IP(`ipconfig`의 IPv4 주소)를 확인한 뒤 휴대폰 브라우저에서 `http://<PC IP>:8000` 으로 접속합니다. (Windows 방화벽 허용 창이 뜨면 `개인 네트워크` 허용)

### 어디서나 (PC를 켜 두지 않아도 됨)
지금 https://imsean629.github.io/janggi-chess-master/ 에 올라가 있습니다. `web/` 폴더는 정적 파일뿐이라 다른 곳(Cloudflare Pages, Netlify 등)에도 그대로 올릴 수 있습니다.
HTTPS 주소로 열면 휴대폰 브라우저 메뉴의 **`홈 화면에 추가`** 로 앱처럼 설치되고, 한 번 열고 나면 오프라인에서도 실행됩니다. (서비스 워커는 HTTPS 또는 localhost에서만 동작)

## 엔진

두 엔진 모두 알파-베타 탐색 + 반복 심화 + 전치표 + 킬러/히스토리 수 정렬 + 정지 탐색 + 체크(장군) 연장을 쓰고, Web Worker에서 돌아 화면이 멈추지 않습니다. 점수는 **두는 쪽 기준**입니다.

| | 장기 | 체스 |
| --- | --- | --- |
| 속도 (일반 PC) | 초당 약 300만 노드, 3초에 8~9수 깊이 | 초당 약 100만 노드, 3초에 11~12수 깊이 (널무브·LMR·퓨틸리티 가지치기 추가) |
| 평가 | 기물 가치(차 13, 포 7, 마 5, 상·사 3, 졸 2) + 위치 가산점 | 기물 가치 + 중반/종반 위치표, 통과한 폰·겹폰·고립 폰, 비숍 쌍, 룩 열린 파일, 종반 킹 몰기 |
| 점수 단위 | `+2.0` ≈ 졸 하나 | `+1.0` ≈ 폰 하나 |
| 규칙 검증 | 규칙별 테스트 + 무작위 대국 장군 판정 대조 | 표준 perft 국면 6종 (수 생성 개수가 공인 값과 일치) |

엔진 안에서는 같은 국면이 반복되면 무승부로 평가합니다.

## 파일

| 파일 | 역할 |
| --- | --- |
| `index.html` | 첫 화면: 장기 / 체스 선택 |
| `janggi.html`, `janggi-app.js`, `janggi-engine.js` | 장기 마스터 화면 · 동작 · 엔진 |
| `chess.html`, `chess-app.js`, `chess-engine.js` | 체스 마스터 화면 · 동작 · 엔진 |
| `style.css` | 공통 스타일 (휴대폰 세로 화면 우선, 다크 모드 지원) |
| `manifest.webmanifest`, `sw.js`, `icon-*` | 홈 화면 추가 / 오프라인 지원 (파일을 고치면 `sw.js`의 `VERSION`을 올려 주세요) |
